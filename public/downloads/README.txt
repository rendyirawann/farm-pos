Letakkan file APK aplikasi tablet di folder ini dengan nama:

    mooda-pos.apk

Setelah file ada, halaman "Aplikasi Tablet" (/admin/download-app) otomatis
menampilkan tombol Download APK untuk tenant yang berlangganan aktif.

Alternatif: set URL unduhan eksternal via .env
    MOBILE_APK_URL="https://cdn.contoh.com/mooda-pos.apk"
    MOBILE_APK_VERSION="1.0.0"

Cara membangun APK ada di: /mobile/README-BUILD-APK.md
